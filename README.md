A tiny Node 22 program for the make.fun bounty
[Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

`main.ts` writes one sentence to `/output/entry.txt`: a pitch for a bizarre
startup idea that sounds absurd until you realise it would actually sell —
renting a grandmother by the hour. No network, no randomness, no input — the
same sentence on every run.

Run it with Node 22:

```sh
node main.ts
```
